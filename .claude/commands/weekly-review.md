# weekly-review

Read CLAUDE.md. Run node scripts/portfolio.mjs weekly-review with Draft the week from collection, attention and compliance. Use --json to inspect full records. Resolve missing input from the user's request and the existing records; never guess a figure, source, actor or evidence. Use a unique ID when names clash.

This command reads collection-week, attention and compliance in one consistent transaction and writes the Monday brief.

Present the reporting period, currency, review state and source where relevant. Missing data stays missing. Local output is a draft for review and must never be sent or published by this recipe.
