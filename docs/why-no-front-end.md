# Why there is no front end

The internal portfolio desk spends its week collecting figures, checking what changed and preparing evidence for a review meeting. Those tasks work through a database and a coding agent. The command library gives the agent repeatable actions; local HTML gives reviewers something readable.

This base has no founder submission portal, mobile app, offline mode, drag-and-drop modelling, charts or shared-user login. Figures arrive through a trusted operator or a mapped spreadsheet import. It does not replace Fundwave's investment calculation modules. Teams requiring continuous self-service submission need that experience scoped and built before switching.
